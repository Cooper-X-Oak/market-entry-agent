## 4. 关键实现变更

### 4.1 Auth、Workspace 与 Permission

- `AuthService.login()` 返回用户全部 active Workspace membership。
- 新增 `GET /api/v1/auth/workspaces` 和 `POST /api/v1/auth/select-workspace`。
- Web 登录后进入 `/workspaces`，用户显式选择 Workspace 后进入 Dashboard。
- `AuthGuard` 不再把 JWT 中可能过期的 role 当作最终权限事实；每次请求从 `tenant_members` 读取当前 active role。

### 4.2 Command、Transaction、Event 与 Outbox

- `TransactionManager` 增加同一异步调用链内的 Ambient Transaction。
- API `IdempotencyInterceptor` 在 Command 外层开启事务，并用 PostgreSQL transaction advisory lock 串行化同租户、同 Endpoint、同 Key 的并发请求。
- 嵌套的业务写入、`domain_events`、`outbox_events` 与 `idempotency_records` 复用外层事务。
- Worker Activity 的幂等记录采用同样的事务和 advisory lock 边界。

### 4.3 Mission、Source、SSE 与 Export

- Mission pause、resume、complete 增加合法状态和 Workflow 存在性约束；重复完成保持幂等。
- Worker 在 API 已持久化 completed 终态时不再因新的 `completedAt` 重复写终态 Event；收尾补丁已编译并在 devserver Worker 生效。
- URL Source 只接受 HTTP(S)，执行 Browser Connector 抓取、对象存储写入、Source upsert 和不可变 Source Snapshot 建立。
- SSE Controller 返回真正的 `Observable<MessageEvent>`；全局响应包装对 `Accept: text/event-stream` 请求直接放行。
- Web 能监听 `event: mission.paused.v1`、`mission.resumed.v1`、`mission.completed.v1` 等命名事件并重新读取投影。
- Mission ZIP 新增 Mission Sources、Sources、Source Snapshots、Progress、Metrics、Domain Events 与 Export Manifest。
