## 7. 失败记录与判定

1. SSE 第一轮只出现 `data:`，没有 `event:`。根因是 Service 返回 `Promise<Observable>`，随后又被全局 Response Envelope 包装。修复后 Wire 明确出现 `event: mission.resumed.v1`，浏览器自动刷新通过。
2. 本地 Temporal time-skipping Test Environment 在默认 10 秒和放宽后的 60 秒均初始化超时，测试业务断言没有开始。该失败保留为测试基础设施问题；同一代码在真实 Temporal Server 上的 Workflow 已完整完成。
3. devserver SSH 偶发连接超时，但现有端口转发、API、PostgreSQL、Temporal UI 与 MinIO Console 验收通道持续可用；临时权限 role 已通过 PostgreSQL 直连恢复为 owner。
4. 验收 Mission 的历史中，API Command 与 Worker Activity 各写了一条 `mission.completed.v1`。没有篡改或删除既有审计历史；Worker 已增加终态已持久化判断并重新部署，后续 Mission 不再因新的 `completedAt` 重复写完成事件。
