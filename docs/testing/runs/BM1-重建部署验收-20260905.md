## 4. 本轮发现并修复的问题

1. Capability Gate 输入类型与领域详情不一致。
2. Seed Action Card 缺少 `targetRoleLabel`。
3. Mission Fixture 的 `maxTargets=40` 超过 Contract 上限 20。
4. 正式 Worker 未注册新增的 Capability、Route、Target、Action 与 Contact Activities。
5. Fixture Evidence ID 跨 Mission 冲突；现按 Mission Namespace 生成。
6. Ecosystem Entity 过早标为 Target，导致预算在 Target Ranking 前耗尽。
7. Research Action Card Fixture 缺少 `researchPlan`。
8. pause 与 resume 共用 Activity 幂等键，导致恢复动作被吞；现按 Signal Sequence 区分。
9. Temporal Workflow 自动化测试的模拟 Activity 列表落后；已同步。

修复后验证：

- 远端 Monorepo Typecheck：`24/24` Packages PASS。
- Temporal Workflow：`3/3` Test Files、`3/3` Tests PASS。
- Connector Contract：`9/9` PASS。
- Agent Fixture：`1/1` PASS。
- 最终 Mission 已完成完整可见业务链。
